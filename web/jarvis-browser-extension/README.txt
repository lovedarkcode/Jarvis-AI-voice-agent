JARVIS Browser Link

1. Download the extension package from the JARVIS page.
2. Unzip it somewhere permanent.
3. Open chrome://extensions (or edge://extensions), enable Developer mode,
   choose Load unpacked, then select the unzipped folder.
4. Refresh the hosted JARVIS page and start a new session.

The extension acts only after JARVIS shows an action card and you choose
Approve. It does not receive your Gemini API key and does not run on other
websites.
